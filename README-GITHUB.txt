LEGEA NR. 198/2023 – ÎNVĂȚARE INTERACTIVĂ

PUBLICARE PE GITHUB PAGES

1. Creați un depozit nou pe GitHub sau deschideți depozitul în care doriți site-ul.
2. Încărcați TOATE fișierele din acest folder direct în rădăcina depozitului.
3. Fișierul index.html trebuie să se vadă pe prima pagină a depozitului, lângă app.css, app.js și data.js.
4. În GitHub: Settings → Pages → Build and deployment.
5. Alegeți: Deploy from a branch → main → /(root) → Save.
6. După publicare, deschideți adresa indicată de GitHub Pages și apăsați Ctrl+F5 dacă vedeți o versiune veche.

IMPORTANT

- Nu încărcați arhiva ZIP ca atare. Mai întâi o dezarhivați.
- Nu mutați index.html într-un subfolder.
- Site-ul nu folosește biblioteci externe și nu are căi absolute, deci funcționează într-un depozit GitHub Pages cu orice nume.
- Progresul se salvează local în browserul și pe dispozitivul folosit.
- Vocea audio este cea în limba română disponibilă în browser/dispozitiv.
